# "I developed a backend REST API for a dabbawala delivery tracking system using FastAPI, SQLModel and SQLite. The system manages orders through four predefined statuses: preparing, picked up, in transit and delivered. I separated the application into models, database configuration and route modules. The order router provides APIs for creating and listing orders with status and date filtering and pagination. I also implemented a daily statistics endpoint that aggregates orders by their status. Through this project I learned FastAPI routing, dependency injection, SQLModel sessions, CRUD operations, query parameters, pagination, date-based filtering and aggregation."

## 🎯 15 QUESTIONS JO INTERVIEWER PUCH SAKTA HAI:
1. Why FastAPI?
FastAPI is a modern Python framework for building APIs with automatic validation, serialization and Swagger documentation.

2. What is SQLModel?
SQLModel allows us to define Python models that can work with SQL databases while also providing data validation.

3. What is table=True?
It tells SQLModel that the class represents a database table.

4. Why Enum?
To restrict order status to predefined valid values.

5. Why Optional[int] for ID?
ID is generated by the database during insertion, so it can initially be None.

6. What is primary_key=True?
It uniquely identifies each database record.

7. What is Depends()?
FastAPI's dependency injection mechanism. I use it to provide a database session to API endpoints.

8. Why session.commit()?
To permanently save the transaction to the database.

9. Why session.refresh()?
To refresh the object with database-generated values such as the ID.

10. What is pagination?
Returning records in smaller portions using skip and limit.

11. Why use routers?
To separate endpoints into modular files instead of putting everything in main.py.

12. What is response_model?
It defines and validates the structure of the API response.

13. Difference between OrderCreate and Order?
Order represents the database table, while OrderCreate represents the input required to create an order.

14. What does model_dump() do?
Converts a Pydantic/SQLModel object into a Python dictionary.

15. How does daily summary work?
It creates a date range, filters orders within that range, counts orders for each status and returns the total and status-wise counts.

8. ⭐ "What is pagination?"
You specifically mentioned it, so prepare this properly.
Pagination means dividing a large set of records into smaller chunks instead of returning everything in one response.

- Example:
skip = 20
limit = 10

- means:
Skip the first 20 records and return the next 10.

- Cross-question:
"Why is pagination needed?"
It reduces response size and avoids loading too many records at once, which improves API performance.

9. ⭐ "What are query parameters?"
Query parameters are optional values provided in the URL to control or filter the API response.

- Example:
/orders/?status=delivered

- Here:
status=delivered

is a query parameter.
- Cross-question:
"What query parameters did you use?"
I used status, creation date, skip and limit.
